# ข้อความของบอท (ฉบับร่าง)

> ใช้กับ: โรงงานลูกชิ้น → ร้านก๋วยเตี๋ยวเปิดใหม่
> เขียนในนามเซลส์ผู้ชาย ("ผม/ครับ") ถ้าเซลส์เป็นผู้หญิงให้เปลี่ยนเป็น "ดิฉัน/ค่ะ"
> ก่อนใช้จริง ต้องแก้ข้อเสนอให้ตรงกับของจริง (ชนิดลูกชิ้น, ส่งถึงร้าน, ราคาโรงงาน, ตัวอย่างฟรี) — อย่าสัญญาสิ่งที่ให้ไม่ได้

## ตัวแปร

| ตัวแปร | ความหมาย | ตัวอย่าง |
|---|---|---|
| `{shop}` | ชื่อร้าน (ถ้าไม่มีให้ตัดออก) | ร้านก๋วยเตี๋ยวเรือป้าแดง |
| `{sales}` | ชื่อเล่นเซลส์ | ต้น |
| `{factory}` | ชื่อโรงงาน | |
| `{source}` | ที่มาของรายชื่อร้าน (ถ้าไม่มีให้ตัดประโยคนั้น) | Google Maps |
| `{oa_link}` | ลิงก์เปิดแชท OA พร้อมรหัสร้าน | `https://line.me/R/oaMessage/%40xxxx/?C1023` |
| `{area}` `{min_order}` `{delivery_days}` `{hours}` | พื้นที่ส่ง / ขั้นต่ำ / วันส่ง / เวลาทำการ | |

## A. บัญชี LINE ปกติ (บอทบนมือถือ)

### A1. ข้อความแรก — แบบ A (เป็นกันเอง)

```text
สวัสดีครับ {shop} 🙏
ผม{sales} ฝ่ายขายโรงงานลูกชิ้น{factory} ครับ
เห็นร้านเพิ่งเปิดใหม่จาก {source} ขอแสดงความยินดีด้วยนะครับ 🎉

โรงงานเราผลิตลูกชิ้นหมู ลูกชิ้นเนื้อ ลูกชิ้นปลา ส่งตรงถึงร้านในราคาโรงงาน
สำหรับร้านเปิดใหม่ มีตัวอย่างให้ลองชิมฟรีครับ

ถ้าสนใจ พิมพ์ "สนใจ" ได้เลย เดี๋ยวส่งใบราคาให้ครับ
ถ้าไม่สะดวก พิมพ์ "ไม่สนใจ" ได้เลยครับ จะไม่ทักมารบกวนอีก 🙏
```

### A1. ข้อความแรก — แบบ B (สั้น)

```text
สวัสดีครับ {shop} 🙏 ยินดีกับการเปิดร้านใหม่ด้วยนะครับ
ผม{sales} จากโรงงานลูกชิ้น{factory} ครับ

ร้านกำลังหาลูกชิ้นเจ้าประจำอยู่ไหมครับ? เราส่งตรงจากโรงงาน ราคาส่ง มีตัวอย่างให้ลองฟรี
สนใจพิมพ์ "สนใจ" / ไม่สนใจพิมพ์ "ไม่สนใจ" ได้เลยครับ ขอบคุณครับ
```

### A2. ร้านสนใจ / ถามราคา (ส่งลิงก์ OA)

```text
ขอบคุณมากครับ 😊
ใบราคาและรายละเอียดทั้งหมดอยู่ใน LINE ทางการของโรงงานครับ
กดลิงก์นี้ แล้วกด "ส่ง" รหัสร้านได้เลย ระบบจะส่งใบราคาให้ทันที 👇
{oa_link}

ถ้ากดลิงก์ไม่ได้ พิมพ์บอกได้เลยครับ เดี๋ยวเจ้าหน้าที่ช่วยครับ
```

### A3. ร้านปฏิเสธ

```text
รับทราบครับ ขอบคุณที่ตอบกลับนะครับ 🙏
ขอให้ร้านขายดี ลูกค้าเต็มร้านครับ
```

### A4. ร้านถามว่าได้เบอร์มาจากไหน / ไม่พอใจ

```text
ขออภัยที่รบกวนครับ 🙏
ทางเราเห็นเบอร์ร้านจาก {source} ครับ
จะไม่ทักมารบกวนอีกแล้วครับ ขอบคุณครับ
```

### A5. ข้อความอื่น ๆ (บอทไม่แน่ใจ → ส่งต่อฝ่ายขาย)

```text
ขอบคุณครับ 🙏 เดี๋ยวเจ้าหน้าที่ฝ่ายขายตอบกลับโดยเร็วที่สุดครับ
```

### A6. ทักซ้ำ 1 ครั้ง (ไม่ตอบภายใน 3 วัน)

```text
สวัสดีครับ {shop} ขอทักอีกครั้งนะครับ 🙏
ถ้าร้านยังหาลูกชิ้นเจ้าประจำอยู่ ยินดีส่งตัวอย่างให้ลองชิมก่อนครับ พิมพ์ "สนใจ" ได้เลย
ถ้าไม่สะดวก ไม่ต้องตอบก็ได้ครับ ทางเราจะไม่ทักมารบกวนอีก
```

## B. LINE OA (ตอบผ่าน Messaging API)

### B1. ต้อนรับเมื่อร้านส่งรหัสเข้ามา

```text
ยินดีต้อนรับครับ {shop} 🙏
นี่คือใบราคาลูกชิ้นโรงงาน{factory} ครับ 👇
```

ตามด้วยรูปใบราคา และปุ่มตอบด่วน: `🎁 ขอตัวอย่างฟรี` `🚚 พื้นที่จัดส่ง` `👤 คุยกับเจ้าหน้าที่`

### B2. ขอตัวอย่างฟรี

```text
ยินดีครับ 🎁 รบกวนขอข้อมูลสำหรับส่งตัวอย่างครับ
1) ชื่อร้าน
2) ที่อยู่ หรือแชร์ตำแหน่งร้าน
3) เบอร์ติดต่อ
4) ลูกชิ้นที่อยากลอง
เจ้าหน้าที่จะยืนยันวันส่งอีกครั้งครับ
```

### B3. พื้นที่จัดส่ง

```text
โรงงานส่งถึงร้านในพื้นที่ {area} ครับ
สั่งขั้นต่ำ {min_order} ส่งทุก{delivery_days}
ถ้าร้านอยู่นอกพื้นที่ พิมพ์บอกทำเลได้เลย เดี๋ยวเจ้าหน้าที่เช็กให้ครับ
```

### B4. คุยกับเจ้าหน้าที่

```text
รับทราบครับ 🙏 เจ้าหน้าที่จะตอบกลับในเวลาทำการ ({hours}) ครับ
```

### B5. ร้านเพิ่มเพื่อน OA เอง (ไม่มีรหัส)

```text
ขอบคุณที่เพิ่มเพื่อนโรงงานลูกชิ้น{factory} ครับ 🙏
รบกวนพิมพ์ชื่อร้านไว้ แล้วเลือกเมนูด้านล่างเพื่อดูใบราคาหรือขอตัวอย่างฟรีได้เลยครับ
```

## C. กฎจัดกลุ่มคำตอบ (บัญชีปกติ)

ตรวจจากบนลงล่าง เจอกลุ่มแรกที่ตรงแล้วหยุด ก่อนเทียบให้ตัดช่องว่างและตัวอักษรซ้ำ (เช่น "สนใจจจ" → "สนใจ")

| ลำดับ | กลุ่ม | ตัวอย่างคำ | ตอบ | สถานะ |
|---|---|---|---|---|
| 1 | ไม่พอใจ / ถามที่มาเบอร์ | ใครให้เบอร์, เอาเบอร์มาจากไหน, สแปม, รำคาญ, อย่าทัก, บล็อก | A4 | `DECLINED` + ห้ามติดต่อ + แจ้งเตือน |
| 2 | ปฏิเสธ | ไม่สนใจ, ไม่เอา, ไม่ต้อง, ไม่ใช้, มีเจ้าประจำแล้ว, ยกเลิก | A3 | `DECLINED` + ห้ามติดต่อ |
| 3 | สนใจ | สนใจ, ราคา, ใบราคา, ตัวอย่าง, ส่งมา, อยากได้, ขอดู, โอเค, ok | A2 | `INTERESTED` |
| 4 | อื่น ๆ | ไม่ตรงกลุ่มไหน รวมถึงสติกเกอร์และรูป | A5 | `REPLIED` + `needs_human` + แจ้งเตือน |

- กลุ่ม 2 ต้องมาก่อนกลุ่ม 3 เพราะ "ไม่สนใจ" มีคำว่า "สนใจ" และ "ไม่ต้องส่งตัวอย่าง" มีคำว่า "ตัวอย่าง"
- การเทียบคำพลาดได้กับประโยคกำกวม เช่น "ราคาเท่าไร ไม่เอาแพงนะ" จะเข้ากลุ่มปฏิเสธ → Phase 6 ใช้ AI ช่วยจัดกลุ่ม
- บอทตอบอัตโนมัติไม่เกิน 2 ครั้งต่อร้าน หลังจากนั้นแจ้งเตือนฝ่ายขายอย่างเดียว

## D. ข้อควรระวัง

- **ข้อความแรกไม่ใส่ลิงก์** — ข้อความจากคนที่ยังไม่ใช่เพื่อนแล้วมีลิงก์ ดูเหมือนมิจฉาชีพ ให้ร้านตอบก่อนแล้วค่อยส่งลิงก์
  (การที่ร้านตอบ "สนใจ" ถือเป็นการยินยอมรับข้อมูลด้วย)
- ส่งข้อความแรกช่วง 14:00–16:30 เลี่ยงช่วงร้านยุ่งตอนเที่ยงและเย็น
- ทักซ้ำได้ไม่เกิน 1 ครั้ง
- ตั้งชื่อและรูปโปรไฟล์บัญชีปกติให้เห็นชัดว่าเป็นโรงงาน เช่น "ฝ่ายขาย ลูกชิ้น{factory}"
- ทดสอบ A/B: ส่งแบบ A และ B อย่างละครึ่ง แล้วดูใน dashboard ว่าแบบไหนได้คำตอบมากกว่า
