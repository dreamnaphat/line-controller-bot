# ข้อความของบอท

> ข้อความที่บอทใช้จริงอยู่ใน [`config/messages.yaml`](../config/messages.yaml) และกฎจัดกลุ่มคำตอบอยู่ใน
> [`config/reply_rules.yaml`](../config/reply_rules.yaml) — ไฟล์นี้อธิบายว่าแต่ละข้อความใช้เมื่อไร
>
> - ข้อความแรกที่เลือกใช้: **Q2** (ตั้งใน `config/settings.yaml` → `opener`)
> - เขียนในนามผู้ชาย ("ผม/ครับ") ถ้าตั้งชื่อบัญชีเป็นผู้หญิงให้เปลี่ยนเป็น "ดิฉัน/ค่ะ"
> - B1 และ B2 มีชนิดลูกชิ้นและข้อเสนอ (ส่งถึงร้าน, ราคาโรงงาน, ตัวอย่างฟรี) ต้องแก้ให้ตรงของจริงก่อนเปิด `auto_pitch`

## ตัวแปร

| ตัวแปร | ความหมาย | มาจาก |
|---|---|---|
| `{shop}` | ชื่อร้าน เติม "ร้าน" ข้างหน้าให้อัตโนมัติ และตัดคำโปรยหลัง " - " ออก เช่น "ก๋วยเตี๋ยวเรือป้าแดง - Boat Noodle" → "ร้านก๋วยเตี๋ยวเรือป้าแดง" (ถ้าไม่มีชื่อใช้ "ทางร้าน") | `"Shop"."name"` |
| `{factory}` | ชื่อโรงงาน | `config/settings.yaml` → `business.factory_name` |
| `{persona}` | ชื่อในบัญชี LINE (ไม่ใช่ชื่อจริงพนักงาน) | `business.persona_name` |
| `{source}` | ที่มาของรายชื่อร้าน | `business.source_text` (ค่าเริ่มต้น "Google Maps") |

บอทจะไม่ส่งข้อความที่ตัวแปรยังว่าง เช่น ถ้ายังไม่ใส่ชื่อโรงงาน บอทจะไม่ส่ง Q1, B1, B2

## A. ข้อความแรก

### Q2. ถามอย่างเดียว (ใช้อยู่)

```text
สวัสดีครับ {shop} เปิดขายอยู่ไหมครับ 🙏
```

ตัวอย่าง: "สวัสดีครับ ร้านก๋วยเตี๋ยวเรือป้าแดง เปิดขายอยู่ไหมครับ 🙏"

### Q1. บอกชื่อสั้น ๆ แล้วถาม (สำรองไว้เทียบผล)

```text
สวัสดีครับ ผม{persona} จากโรงงานลูกชิ้น{factory} ครับ
{shop} เปิดขายแล้วใช่ไหมครับ 🙏
```

Q2 ร้านมักนึกว่าเป็นลูกค้าจะมากินจึงตอบเร็ว แต่พอข้อความถัดไปเป็นการขาย บางร้านอาจบล็อกหรือกดรายงาน
ให้ดูใน dashboard ว่ามีร้านบล็อกมากไหม ถ้ามากค่อยลองสลับเป็น Q1

## B. บอทตอบอัตโนมัติ (1 ครั้งต่อร้าน)

### B1. ร้านตอบทั่วไป (เปิดแล้ว, ใช่, มีอะไรครับ, ใครครับ, สติกเกอร์)

```text
ขอบคุณครับ 🙏
ผมติดต่อจากโรงงานลูกชิ้น{factory} ครับ โรงงานเราผลิตลูกชิ้นหมู ลูกชิ้นเนื้อ ลูกชิ้นปลา ส่งตรงถึงร้านในราคาโรงงาน
ร้านเปิดใหม่มีตัวอย่างให้ลองชิมฟรีครับ
สนใจให้ผมส่งใบราคาหรือตัวอย่างไปให้ไหมครับ
```

### B2. ร้านยังไม่เปิด

ร้านที่กำลังเตรียมเปิดคือช่วงที่กำลังเลือกเจ้าวัตถุดิบ เป็นโอกาสที่ดีที่สุด

```text
ขอบคุณครับ 🙏
ผมติดต่อจากโรงงานลูกชิ้น{factory} ครับ ถ้าร้านกำลังหาเจ้าลูกชิ้นอยู่ ส่งตัวอย่างให้ลองชิมก่อนเปิดร้านได้เลยครับ
สนใจให้ส่งใบราคาไว้ดูก่อนไหมครับ
```

### B3. ร้านปิดกิจการแล้ว

```text
ขอบคุณที่แจ้งครับ ขออภัยที่รบกวนนะครับ 🙏
```

### B4. ร้านไม่พอใจ / ถามว่าได้เบอร์มาจากไหน

```text
ขออภัยที่รบกวนครับ 🙏 ทางเราเห็นเบอร์ร้านจาก {source} ครับ
จะไม่ทักมารบกวนอีกครับ
```

### B5. ร้านปฏิเสธ

```text
รับทราบครับ ขอบคุณที่ตอบกลับนะครับ 🙏 ขอให้ร้านขายดีครับ
```

### B6. ทักผิดเบอร์

เบอร์บน Google Maps อาจเก่าหรือเป็นของคนอื่น

```text
ขออภัยครับ น่าจะทักผิดเบอร์ ขอโทษที่รบกวนนะครับ 🙏
```

## C. ข้อความสำเร็จรูปสำหรับพนักงาน (คุยต่อเอง)

### C1. ส่งใบราคา

```text
นี่คือใบราคาลูกชิ้นของโรงงานครับ 👇
สั่งขั้นต่ำ {min_order} ส่งถึงร้านในพื้นที่ {area} ครับ
```

แนบรูปใบราคาต่อท้าย

### C2. นัดส่งตัวอย่าง

```text
ยินดีครับ 🎁 รบกวนขอที่อยู่หรือแชร์ตำแหน่งร้าน และเบอร์ติดต่อด้วยนะครับ
แล้วผมจะนัดวันส่งตัวอย่างให้อีกครั้งครับ
```

## D. กฎจัดกลุ่มคำตอบ

ตรวจจากบนลงล่าง เจอกลุ่มแรกที่ตรงแล้วหยุด ก่อนเทียบ บอทตัดช่องว่าง ตัวอักษรซ้ำ (เช่น "เปิดดดด" → "เปิด") และแปลงเป็นตัวพิมพ์เล็ก

| ลำดับ | กลุ่ม | ตัวอย่างคำ | บอทตอบ | สถานะ |
|---|---|---|---|---|
| 1 | ไม่พอใจ / ถามที่มาเบอร์ | ใครให้เบอร์, เอาเบอร์มาจากไหน, สแปม, รำคาญ, อย่าทัก, บล็อก | B4 | `DECLINED` + ห้ามติดต่อ + แจ้งเตือน |
| 2 | ทักผิดเบอร์ | ผิดเบอร์, ทักผิด, ไม่ใช่ร้าน | B6 | `DECLINED` + ห้ามติดต่อ |
| 3 | ปฏิเสธ | ไม่สนใจ, ไม่เอา, ไม่ต้อง, มีเจ้าประจำแล้ว | B5 | `DECLINED` + ห้ามติดต่อ |
| 4 | ปิดกิจการ | ปิดกิจการ, ปิดร้านแล้ว, เลิกขาย, เซ้งแล้ว, ไม่เปิดแล้ว | B3 | `CLOSED` + ห้ามติดต่อ |
| 5 | ยังไม่เปิด | ยังไม่เปิด, ยังไม่ได้เปิด, กำลังจะเปิด, เปิดเดือนหน้า | B2 | `PITCHED` (ร้าน: ยังไม่เปิด) |
| 6 | อื่น ๆ | เปิด, ใช่ค่ะ, มีอะไรครับ, ใครครับ, สติกเกอร์, รูป | B1 | `PITCHED` (ร้าน: เปิดแล้ว ถ้ามีคำว่า "เปิด" หรือ "ใช่") |

จุดที่ระวังไว้ในโค้ดแล้ว (มีเทสต์ครบ):

- **"เปิด" มีคำว่า "ปิด" อยู่ในตัว** เช่น "เปิดร้านแล้ว" มี "ปิดร้านแล้ว" อยู่ข้างใน → pattern กลุ่มปิดกิจการใช้ `(?<!เ)ปิด`
- "วันนี้ปิด" (หยุดวันนี้) ไม่ใช่ปิดกิจการ → กลุ่ม 4 ใช้วลีเต็ม ไม่ใช้คำว่า "ปิด" เดี่ยว ๆ
- "ไม่สนใจ" มีคำว่า "สนใจ" และ "ยังไม่เปิด" มีคำว่า "เปิด" → กลุ่มปฏิเสธและกลุ่มยังไม่เปิดตรวจก่อนกลุ่มอื่น ๆ
- ประโยคกำกวม เช่น "ราคาเท่าไร ไม่เอาแพงนะ" จะตกกลุ่มปฏิเสธ → Phase 5 อาจใช้ AI ช่วยจัดกลุ่ม

## E. ข้อควรระวัง

- ข้อความแรกไม่ใส่ลิงก์และไม่ขายของ — ให้ร้านตอบก่อน
- ทักช่วง 14:00–16:30 เลี่ยงช่วงร้านยุ่งตอนเที่ยงและเย็น
- ไม่ทักซ้ำ ถ้าร้านไม่ตอบภายใน 7 วันถือว่าจบ
- บอทตอบอัตโนมัติแค่ 1 ครั้ง ที่เหลือพนักงานคุยเอง
