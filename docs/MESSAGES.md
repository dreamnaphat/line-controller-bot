# ข้อความของบอท (ฉบับร่าง v2)

> ใช้กับ: โรงงานลูกชิ้น → ร้านก๋วยเตี๋ยวเปิดใหม่ ทักจาก LINE ของพนักงาน
> เขียนในนามพนักงานผู้ชาย ("ผม/ครับ") ถ้าเป็นผู้หญิงให้เปลี่ยนเป็น "ดิฉัน/ค่ะ" หรือ "เรา/ค่ะ"
> ก่อนใช้จริง ต้องแก้ข้อเสนอให้ตรงกับของจริง (ชนิดลูกชิ้น, ส่งถึงร้าน, ราคาโรงงาน, ตัวอย่างฟรี) — อย่าสัญญาสิ่งที่ให้ไม่ได้

## ตัวแปร

| ตัวแปร | ความหมาย | ตัวอย่าง |
|---|---|---|
| `{shop}` | ชื่อร้าน (ถ้าไม่มีใช้คำว่า "ทางร้าน") | ร้านก๋วยเตี๋ยวเรือป้าแดง |
| `{sales}` | ชื่อเล่นพนักงาน | ต้น |
| `{factory}` | ชื่อโรงงาน | |
| `{source}` | ที่มาของรายชื่อร้าน | Google Maps |
| `{area}` `{min_order}` | พื้นที่ส่ง / ขั้นต่ำการสั่ง | |

## A. คำถามเปิดบทสนทนา (ข้อความแรก)

### Q1. บอกชื่อสั้น ๆ แล้วถาม (แนะนำ)

```text
สวัสดีครับ ผม{sales} จากโรงงานลูกชิ้น{factory} ครับ
{shop}เปิดขายแล้วใช่ไหมครับ 🙏
```

### Q2. ถามอย่างเดียว

```text
สวัสดีครับ {shop}เปิดขายอยู่ไหมครับ 🙏
```

Q2 ร้านมักนึกว่าเป็นลูกค้าจะมากินจึงตอบเร็ว แต่พอข้อความถัดไปเป็นการขาย บางร้านอาจรู้สึกไม่ดีแล้วบล็อกหรือกดรายงาน
ซึ่งเสี่ยงกับบัญชีพนักงาน ส่วน Q1 บอกแค่ชื่อกับโรงงาน ยังสั้นและเป็นธรรมชาติ แต่ตรงไปตรงมากว่า
แนะนำเริ่มที่ Q1 หรือส่งทั้งสองแบบอย่างละครึ่ง แล้วดูใน dashboard ว่าแบบไหนได้คำตอบมากกว่าและโดนบล็อกน้อยกว่า

## B. บอทตอบอัตโนมัติ (1 ครั้งต่อร้าน)

### B1. ร้านตอบทั่วไป (เปิดแล้ว, ใช่, มีอะไรครับ, ใครครับ, สติกเกอร์)

```text
ขอบคุณครับ 🙏
ผมติดต่อจากโรงงานลูกชิ้น{factory} ครับ โรงงานเราผลิตลูกชิ้นหมู ลูกชิ้นเนื้อ ลูกชิ้นปลา ส่งตรงถึงร้านในราคาโรงงาน
ร้านเปิดใหม่มีตัวอย่างให้ลองชิมฟรีครับ
สนใจให้ผมส่งใบราคาหรือตัวอย่างไปให้ไหมครับ
```

### B2. ร้านยังไม่เปิด

ร้านที่กำลังเตรียมเปิดคือช่วงที่กำลังเลือกเจ้าวัตถุดิบ เป็นโอกาสที่ดีที่สุด

```text
ขอบคุณครับ 🙏 กำลังเตรียมเปิดร้านอยู่ใช่ไหมครับ
ผมติดต่อจากโรงงานลูกชิ้น{factory} ครับ ถ้าร้านกำลังหาเจ้าลูกชิ้นอยู่ ส่งตัวอย่างให้ลองชิมก่อนเปิดร้านได้เลยครับ
สนใจให้ส่งใบราคาไว้ดูก่อนไหมครับ
```

### B3. ร้านปิดกิจการแล้ว

```text
ขอบคุณที่แจ้งครับ ขออภัยที่รบกวนนะครับ 🙏
```

### B4. ร้านไม่พอใจ / ถามว่าได้เบอร์มาจากไหน

```text
ขออภัยที่รบกวนครับ 🙏 ทางเราเห็นเบอร์ร้านจาก {source} ครับ
จะไม่ทักมารบกวนอีกครับ
```

### B5. ร้านปฏิเสธ

```text
รับทราบครับ ขอบคุณที่ตอบกลับนะครับ 🙏 ขอให้ร้านขายดีครับ
```

## C. ข้อความสำเร็จรูปสำหรับพนักงาน (คุยต่อเอง)

### C1. ส่งใบราคา

```text
นี่คือใบราคาลูกชิ้นของโรงงานครับ 👇
สั่งขั้นต่ำ {min_order} ส่งถึงร้านในพื้นที่ {area} ครับ
```

แนบรูปใบราคาต่อท้าย

### C2. นัดส่งตัวอย่าง

```text
ยินดีครับ 🎁 รบกวนขอที่อยู่หรือแชร์ตำแหน่งร้าน และเบอร์ติดต่อด้วยนะครับ
แล้วผมจะนัดวันส่งตัวอย่างให้อีกครั้งครับ
```

## D. กฎจัดกลุ่มคำตอบ

ตรวจจากบนลงล่าง เจอกลุ่มแรกที่ตรงแล้วหยุด ก่อนเทียบให้ตัดช่องว่างและตัวอักษรซ้ำ (เช่น "เปิดดดด" → "เปิด")

| ลำดับ | กลุ่ม | ตัวอย่างคำ | บอทตอบ | สถานะ |
|---|---|---|---|---|
| 1 | ไม่พอใจ / ถามที่มาเบอร์ | ใครให้เบอร์, เอาเบอร์มาจากไหน, สแปม, รำคาญ, อย่าทัก, บล็อก | B4 | `DECLINED` + ห้ามติดต่อ + แจ้งเตือน |
| 2 | ปฏิเสธ | ไม่สนใจ, ไม่เอา, ไม่ต้อง, มีเจ้าประจำแล้ว | B5 | `DECLINED` + ห้ามติดต่อ |
| 3 | ปิดกิจการ | ปิดกิจการ, ปิดร้านแล้ว, เลิกขาย, เซ้งแล้ว, ไม่ได้ขายแล้ว, ไม่เปิดแล้ว | B3 | `CLOSED` + ห้ามติดต่อ |
| 4 | ยังไม่เปิด | ยังไม่เปิด, ยังไม่ได้เปิด, กำลังจะเปิด, ใกล้เปิด, เปิดเดือนหน้า | B2 | `PITCHED` (ร้าน: ยังไม่เปิด) |
| 5 | อื่น ๆ | เปิด, ใช่ค่ะ, มีอะไรครับ, ใครครับ, สติกเกอร์, รูป | B1 | `PITCHED` (ร้าน: เปิดแล้ว ถ้ามีคำว่า "เปิด") |

จุดที่ต้องระวังตอนเขียนโค้ด:

- **"เปิด" มีคำว่า "ปิด" อยู่ในตัว** (เ + ปิด) เช่น "เปิดร้านแล้ว" มี "ปิดร้านแล้ว" อยู่ข้างใน
  → คำในกลุ่ม 3 ที่ขึ้นต้นด้วย "ปิด" ต้องเช็กว่าไม่มี "เ" นำหน้า (regex `(?<!เ)ปิด`)
- "ยังไม่เปิด" มีคำว่า "เปิด" → กลุ่ม 4 ต้องมาก่อนกลุ่ม 5
- "วันนี้ปิด" (หยุดวันนี้) ไม่ใช่ปิดกิจการ → กลุ่ม 3 ใช้วลีเต็ม ไม่ใช้คำว่า "ปิด" เดี่ยว ๆ
- ประโยคกำกวมตกไปกลุ่ม 5 ได้คำตอบ B1 ซึ่งยังเหมาะกับทุกร้าน แล้วพนักงานดูต่อ
- หลังบอทตอบแล้ว ข้อความใหม่ทั้งหมด → แจ้งพนักงาน ยกเว้นกลุ่ม 1–2 ที่บอทปิดบทสนทนาให้ได้

## E. ข้อควรระวัง

- ข้อความแรกไม่ใส่ลิงก์และไม่ขายของ — ให้ร้านตอบก่อน
- ทักช่วง 14:00–16:30 เลี่ยงช่วงร้านยุ่งตอนเที่ยงและเย็น
- ค่าเริ่มต้นไม่ทักซ้ำ ถ้าร้านไม่ตอบภายใน 7 วันถือว่าจบ
- บอทตอบอัตโนมัติแค่ 1 ครั้ง ที่เหลือพนักงานคุยเอง
