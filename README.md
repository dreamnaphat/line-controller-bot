# line-controller-bot

บอทสำหรับโรงงานลูกชิ้น ใช้ทักร้านก๋วยเตี๋ยวเปิดใหม่ทาง LINE จากเบอร์โทรในฐานข้อมูล Neon

- ควบคุมแอป LINE ของพนักงานบนมือถือ Android (ADB + uiautomator2)
- ทักด้วยคำถามสั้น ๆ ว่าร้านเปิดแล้วหรือยัง ตอบกลับอัตโนมัติ 1 ครั้ง แล้วส่งต่อให้พนักงาน
- บันทึกว่าร้านไหนตอบแล้วใน Neon และแจ้งเตือนพนักงานทาง Telegram
