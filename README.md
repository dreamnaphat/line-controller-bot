# line-controller-bot

บอทสำหรับโรงงานลูกชิ้น ใช้ทักร้านก๋วยเตี๋ยวเปิดใหม่ทาง LINE จากเบอร์โทรในฐานข้อมูล Neon
แล้วติดตามและตอบกลับอัตโนมัติ

- บัญชี LINE ปกติบนมือถือ Android (ADB + uiautomator2) ใช้ทักครั้งแรก
- LINE OA + Messaging API ใช้คุยต่อ ตอบอัตโนมัติ และเก็บลูกค้าระยะยาว
