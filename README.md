# line-controller-bot

บอทสำหรับโรงงานลูกชิ้น ใช้ทักร้านก๋วยเตี๋ยวเปิดใหม่ทาง LINE จากเบอร์โทรในตาราง `"Shop"` บน Neon

- ควบคุมแอป LINE บนมือถือ Android (Honor 400 Pro) ผ่าน ADB + uiautomator2
- ทักด้วยคำถามสั้น ๆ ว่าร้านเปิดขายอยู่ไหม บันทึกว่าร้านไหนตอบแล้ว ตอบกลับอัตโนมัติ 1 ครั้ง แล้วส่งต่อให้พนักงาน
- ดึงร้านใหม่เข้าคิวเองทุกวัน และเกลี่ยโควตาให้ทักร้านแต่ละรอบหมดภายในสิ้นเดือน
- หน้าเว็บ (Streamlit) ดูการทำงานของบอทสด ๆ เริ่ม/หยุดบอท และให้พนักงานดูร้านที่ตอบ บันทึกผล นัดทักใหม่ และดู funnel
- สถานะทั้งหมดเก็บใน Neon (schema `line_bot`) โดยไม่แตะตารางเดิม

## คำสั่ง

รันในโฟลเดอร์โปรเจกต์ หลังติดตั้งตาม [docs/SETUP.md](docs/SETUP.md)

| คำสั่ง | ใช้ทำอะไร |
|---|---|
| `python -m bot doctor` | ตรวจการเชื่อมต่อคอมพิวเตอร์ → มือถือ → LINE |
| `python -m bot dump <ชื่อหน้าจอ>` | เก็บภาพและโครงสร้างหน้าจอ LINE ไว้หา selector |
| `python -m bot init-db` | สร้างตารางของบอทใน Neon (รันซ้ำได้ — `run` ทำให้เองทุกครั้งที่เริ่ม) |
| `python -m bot import [--commit]` | ดึงร้านใหม่จาก `"Shop"` เข้าคิว (ไม่ใส่ `--commit` = ดูตัวอย่างเท่านั้น) |
| `python -m bot test-add --phone 08xxxxxxxx` / `test-clear` | เพิ่ม/ลบร้านสมมติที่ใช้เบอร์ทีม (โหมดทดสอบทักได้เฉพาะเบอร์ใน `TEST_PHONES`) |
| `python -m bot run [--once] [--now] [--max N]` | ทักร้านจากคิว (ค้นเบอร์ → เพิ่มเพื่อน → เปลี่ยนชื่อ → ส่งข้อความ) ตามโควตาและช่วงเวลา แล้วตรวจคำตอบของร้านตอนที่ไม่ได้ทักร้าน |
| `python -m bot status` | ดูจำนวนร้านในคิวแยกตามสถานะ และโควตาวันนี้ |
| `python -m bot replies` | ดูร้านที่ตอบแล้วและรอพนักงานคุยต่อ |
| `python -m bot check-replies` | ตรวจคำตอบของร้านตอนนี้เลย 1 รอบ (การแจ้งเตือน + หน้ารายการแชท) |
| `python -m bot dashboard [--lan]` | เปิดหน้าเว็บ: **บอท** (สถานะสด เริ่ม/หยุดบอท มือถือ ร้านแต่ละรอบ), **ติดตามร้าน** (ร้านที่ตอบ บันทึกผล funnel), **เครื่องมือทดสอบ** (เบอร์ทีม ร้านทดสอบ สั่งทีละขั้น) |
| `python -m bot poc --phone 08xxxxxxxx [--step] [--rename] [--send]` | ทดลองค้นเบอร์ เพิ่มเพื่อน และพิมพ์ข้อความแรกกับเบอร์ทดสอบ |
